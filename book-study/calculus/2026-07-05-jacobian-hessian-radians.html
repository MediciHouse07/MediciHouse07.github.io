1. Radians Explain the Extra r

Definition

A radian measures an angle by comparing arc length with radius.

θ=arc lengthradius

So if the arc length equals the radius, the angle is 1 radian.

Polar patch

For a small polar sector, the curved side has length rdθ and the radial thickness is dr.

dA≈(rdθ)(dr)=rdrdθ
Memory rule: the same angle cuts a longer arc farther from the origin, so polar area needs the extra factor r.

Polar stretch

The curved side of a tiny polar sector grows with radius.

x=rcosθ,y=rsinθ,J=r

4. Hessian: Same Shape, Different Question

Jacobian matrix

Uses first derivatives of a transformation. It asks how input motion changes output motion or area.

xuxvyuyv

Hessian matrix

Uses second derivatives of one scalar function. It asks how the graph is curving near a critical point.

fxxfxyfyxfyy

Simmons does not appear to name the capital-H Hessian matrix explicitly. He teaches the ingredients as second partial derivatives and then uses the discriminant in the second derivative test.

D=fxxfyy-(fxy)2

5. Clean Relationship

The reason Jacobians and Hessians look similar is that a Hessian is the Jacobian of the gradient.

∇f=(fx,fy)
J(∇f)=fxxfxyfyxfyy

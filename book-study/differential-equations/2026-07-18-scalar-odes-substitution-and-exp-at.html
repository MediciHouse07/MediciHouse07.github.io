1. The Scalar Model Comes First

Before understanding a matrix differential equation, study one scalar equation:

dudt=λu

We need a function whose derivative is λ times itself. Exponentials have exactly that property:

u(t)=Ceλt

The role of C

C is the starting amount. Setting t=0 gives u(0)=C.

The role of λ

λ controls the change: negative means decay, positive means growth, zero means steady, and a complex value can create oscillation.

Important correction: the integration constant is not added to the final exponential solution. It becomes multiplicative because e-3t+K=eKe-3t, and the constant eK is renamed C.

2. Why Separation of Variables Is Legitimate

For the example u′=-3u, first assume u≠0 and divide by u:

1ududt=-3

The rigorous next step integrates both sides with respect to the same variable t:

∫1u(t)dudtdt=∫-3dt

Only then do we use substitution on the left. Let s=u(t), so ds=u′(t)dt.

∫u′(t)u(t)dt=∫1sds=ln|s|+K
Divide

Put every u-dependent factor with du.

Integrate in t

The equality is still an equality of functions of time.

Substitute

Rewrite the left integral using s=u(t).

Exponentiate

Remove the logarithm and absorb eK into C.

3. Definite Integrals and Changed Limits

For a definite integral, the original variable is still t:

∫0Tu′(t)u(t)dt=∫u(0)u(T)1sds

The new limits come from the same endpoints: t=0 maps to s=u(0), and t=T maps to s=u(T).

The variable did not split into two unrelated integrations. The s-integral is a rewritten form of the original t-integral.

Even if u(t) wiggles or revisits values, the endpoint formula can still hold because the integrand is the derivative of ln|u(t)|. The essential restriction is that the whole path must stay away from zero.

4. The Zero-Crossing Restriction

Safe interval

If u(t)≠0 throughout the interval, then

∫0Tu′(t)u(t)dt=ln|u(T)|-ln|u(0)|

Zero crossing

If u(c)=0, then u′u is undefined at t=c. The integral must be split and treated as improper; it may diverge.

Same singularity, two views: in the original variable, the problem occurs at a time t=c where u(c)=0. After substitution, the same problem appears as 1s being undefined at s=0.

5. Did the Dimension Change?

No physical or mathematical object was reduced from two dimensions to one. The graph of u(t) is drawn in the two-coordinate (t,u) plane so we can see how one scalar value changes with time.

The function

u(t) is one scalar output for each scalar input t.

The graph

The picture uses two axes because it displays input and output together.

The substitution

s=u(t) follows the visited output values directly on the real number line.

The change to a one-dimensional s-line is therefore a change of coordinate for integration, not a loss of dimension.

6. Bridge to Linear Algebra

The matrix system is

dudt=Au

An eigenvector x satisfies

Ax=λx

Along that direction, the matrix equation becomes the scalar equation again. A single eigenvector mode has the form

u(t)=ceλtx

The initial vector determines the coefficients of the eigenvector modes, while each eigenvalue determines how its mode changes over time.

Initial condition

u(0)=c1x1+c2x2

This fixes the mode coefficients.

Time evolution

u(t)=c1eλ1tx1+c2eλ2tx2

The matrix exponential packages these modes as u(t)=eAtu(0).

7. The Questions That Moved the Lesson Forward

Is this differential equations or linear algebra?

Both. Time evolution is the differential-equation part; the matrix, eigenvalues, and eigenvectors are the linear-algebra part.

Why is the answer not e-3t+C?

Because differentiating an added constant does not reproduce the required right side. The constant becomes a multiplier after exponentiation.

Can we integrate both sides blindly?

No. First express an equality in a common variable, integrate both sides in that variable, and then apply a valid substitution.

Do only the endpoints matter?

They do for a logarithmic derivative on an interval where the function stays nonzero. A zero crossing creates a singularity.

Does substitution make a 2D problem 1D?

No. The two-axis graph visualizes one scalar function. The substitution follows its output values on the one-dimensional real line.

Where does the matrix exponential come from?

Every eigenvector mode behaves like a scalar exponential eλt; eAt combines all modes.

1. Core Problem

Original difficulty

Differential equations mix a function with its derivatives. That makes direct algebraic solving hard.

y′(t)+2y(t)=0

Transform strategy

Laplace transform moves the equation into an algebraic space where derivative terms become expressions in s and Y(s).

differential equation→algebra→inverse transform

2. Definition

The transform views y(t) through an exponential discount lens.

L{y(t)}=∫0∞e-sty(t)dt=Y(s)

Small s

A smaller s discounts the future less, so it keeps more long-term behavior.

Large s

A larger s discounts the future more, so it emphasizes early-time behavior.

3. Why Exponentials Help

Exponentials are useful because differentiating them returns the same exponential multiplied by a simple factor.

ddte-st=-se-st
Memory rule: the transform is designed so differentiation can be traded for multiplication by s, plus initial-value terms.

Key point: higher derivatives pull in the initial status of lower derivatives all the way back to y(0).

5. Example Worked Thread

For the initial-value problem:

y′+2y=0,y(0)=3

Transform both sides and substitute the initial condition.

(sY-3)+2Y=0
Y(s)=3s+2

The inverse table maps this back to:

y(t)=3e-2t

6. Inverse Transform Idea

Forward

Move from a time function to an algebraic expression.

y(t)→Y(s)

Backward

Use a transform table or algebraic matching to recover the time function.

Y(s)→y(t)

7. Big Picture

Start with an IVP
Apply Laplace rules
Solve algebraically for Y(s)
Invert back to y(t)
One-sentence memory hook: Laplace transform turns a differential-equation problem into an algebra problem while preserving the initial status of the system.

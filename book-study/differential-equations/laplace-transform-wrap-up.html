Laplace Transform – Socratic Wrap-Up

Boyce & DiPrima – Differential Equations

1. Core Problem

Differential equations mix y(t), y'(t), y''(t), making algebraic solving impossible.

2. Why Transform Exists

Convert derivatives into algebra so equations become solvable.

3. Definition

L{y(t)} = ∫₀^∞ e^{-st} y(t) dt = Y(s)

4. Lens Idea

Small s = long-term view
Large s = short-term view

5. Why Exponentials

d/dt (e^{-st}) = -s e^{-st}

6. Integration by Parts Result

L{y'} = sY(s) - y(0)

7. Higher Derivatives

L{y''} = s²Y - s y(0) - y'(0)
L{y'''} = s³Y - s² y(0) - s y'(0) - y''(0)

8. Example

y' + 2y = 0, y(0)=3 → Y = 3/(s+2)

9. Inverse Idea

Use transform table to map Y(s) back to y(t)

10. Big Insight

Differential equation → algebra → inverse transform → solution

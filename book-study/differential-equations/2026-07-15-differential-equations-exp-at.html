1. From One Equation to a System

A single first-order differential equation has one changing quantity. A system has several changing quantities collected into a vector.

dudt=Au

Scalar memory

dudt=au⇒u(t)=eatu(0)

Matrix version

dudt=Au⇒u(t)=eAtu(0)

2. What Is eAt?

The matrix exponential is defined by the same power series as the ordinary exponential. The only difference is that powers of the number are replaced by powers of the matrix.

eAt=I+At+(At)22!+(At)33!+⋯
Memory rule: eAt is the machine that moves the initial vector u(0) forward to time t.

3. Eigenvectors Make the System Decouple

The easiest case happens when the initial vector points in an eigenvector direction.

Ax=λx⇒eAtx=eλtx

So the complicated matrix system becomes separate scalar exponential growth or decay along eigenvector directions.

find eigenvectors
split the initial vector
multiply each part by eλt
add the pieces back

4. The Lecture Example on the Board

The board shows a triangular system of the form:

du1dt=-u1+2u2du2dt=-2u2

That corresponds to this matrix:

A=[-120-2]

Because the matrix is triangular, the eigenvalues are visible on the diagonal: -1 and -2. Both are negative, so both modes decay.

5. Matrix Exponential for the Example

For the board matrix, the exponential has the form:

eAt=[e-t2(e-t-e-2t)0e-2t]

The diagonal entries show the two decay speeds. The upper-right entry shows coupling: u2 feeds into u1.

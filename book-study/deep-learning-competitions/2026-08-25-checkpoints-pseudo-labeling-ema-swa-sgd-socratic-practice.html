1. Checkpoint = a Saved Training State

When validation performance reaches its best point and later gets worse, the useful model is often not the final epoch. A checkpoint is a saved snapshot of the model at a particular training moment.

Best validation point

Keep the checkpoint whose validation metric is best or validation loss is lowest.

Later overfitting

Training loss may keep falling while validation performance deteriorates; do not replace the best checkpoint just because training continued.

Mental model: a checkpoint is a save point in a game—one recoverable version of the model.

2. Pseudo-Labeling

Use the trained model to predict unlabeled data, keep only very confident predictions, treat those predictions as temporary labels, then retrain with the enlarged training set.

trained model→predict unlabeled data→keep high-confidence labels→retrain

For a binary cat classifier, confidence can work in both directions:

P(cat)>0.98⇒pseudo-label catP(cat)<0.02⇒pseudo-label not-cat

The principle is not “only keep high positive probability”; it is “keep predictions where the model is highly confident about whichever class it chooses.”

3. EMA — Exponential Moving Average

EMA keeps a continuously smoothed version of the model weights. Recent states matter more; older states fade exponentially.

θEMA,new=βθEMA,old+(1−β)θcurrent
Effect: one noisy update moves the averaged model only partway, instead of making the final weights jump completely.

4. SWA — Stochastic Weight Averaging

SWA starts after a chosen point in training, then periodically averages model states along the later noisy optimization path. The selected states are normally taken by a fixed schedule and are weighted roughly equally.

θSWA=1K∑k=1Kθk

EMA

Continuous averaging; recent weights count more.

SWA

Periodic averaging after a chosen start point; selected late-training states count roughly equally.

“Stochastic” does not mean randomly choosing old checkpoints. It refers to the noisy stochastic optimization path that produces the weight states being averaged.

5. What Stochastic Gradient Descent Means

SGD = Stochastic Gradient Descent. Strictly, it updates from one randomly chosen training example at a time.

θnew=θold−η∇L

The gradient from one random example is noisy, so the path moves downhill with zigzags.

Stochastic GD

Batch size = 1. Useful for online or streaming settings, but very noisy and inefficient on modern GPUs.

Mini-batch GD

Use a small random batch such as 32 or 128. This is the practical deep-learning default.

Full-batch GD

Use the entire training set for each update. Stable but usually too expensive for large deep-learning datasets.

Terminology warning: in modern deep learning, “SGD” is often used loosely for mini-batch SGD, even though strict stochastic gradient descent uses one sample per update.

6. Final Mental Model

EMA

Smooth the recent trajectory, exponentially favoring newer weights.

SWA

Average several scheduled late-training states to find a stable center of the region being explored.

Core distinction: EMA changes the weighting rule; SWA changes when and which later states are collected for an approximately equal-weight average.

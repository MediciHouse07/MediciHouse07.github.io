1. Validation and TTA Use Deterministic Transforms

Training augmentation can be random, but validation should be stable. The book recommends deterministic validation/TTA transforms such as resize and normalization rather than random crops or random color changes.

Reason: if validation preprocessing changes randomly between runs, the metric itself gains avoidable randomness.

2. CV Fine-Tuning: Freeze, Partially Unfreeze, or Train All

For a pretrained image backbone, there are three common transfer-learning choices:

StrategyWhat trains
Head onlyFreeze the backbone; train only the new task-specific head.
Partial fine-tuningUnfreeze the last few blocks plus the head.
Full fine-tuningTrain the new head and all backbone parameters.

The book's recommendation is that replacing the classification head and fine-tuning all parameters usually performs better; freezing or layered learning rates are worth trying for large models with small datasets.

3. What the Classification Head Is

In the simplest classifier, the head maps the backbone's learned feature vector into class logits:

h→Wh+b→logits→softmax probabilities

The head can contain more than one layer, but its final layer has one output logit per class.

4. Complete Toy Vector Example: Original Pretrained Model

Represent a tiny input image as:

x= 1021

Use a toy backbone matrix:

B= 1010 0101

The backbone produces the feature vector:

h=Bx= 31

Suppose the original pretrained task had four classes. Its old head is therefore a matrix with four output rows:

Wold= 10 01 11 −11

So the old model maps a 2-dimensional feature vector to 4 logits:

Wold:2→4

5. Replacing the Old Head for a New 3-Class Task

For a new cat/dog/rabbit competition, keep the backbone output size at 2 but replace the old 4-output head with a new 3-output head:

Wnew= 10 01 −11

Apply it to the same feature vector:

znew= Wnewh= 31−2

Those are the three logits. Softmax then converts them into class probabilities.

Core distinction: the backbone matrix B creates the hidden/feature vector. The head matrix W maps that vector to the task's logits. The number of rows in the final head matrix equals the number of output classes.

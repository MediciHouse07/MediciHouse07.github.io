1. Why Ordinary CV Can Become an Optimistic Judge

Suppose ordinary CV compares learning rates and reports:

Learning rate 0.1

CV score: 0.75

Learning rate 0.01

CV score: 0.82

The CV result has already influenced the choice: 0.01 is selected because it scored 0.82. Therefore, the same 0.82 is no longer a completely fresh evaluation of the selection decision.

Core source point: separate the data used to tune from the data used to judge the tuned procedure.

Use 5 outer splits. Inside each outer split, the remaining 4 folds form a 4-fold inner CV. Test exactly 10 candidate learning rates.

5×4×10=200

So this illustrative setup requires 200 inner-CV model fits.

3. What Happens Inside One Outer Split

Take the split where E is kept aside. Only A, B, C, and D participate in the inner CV.

A+B+C+D|E

For each of the 10 candidate learning rates, run 4 inner-fold validations. Each candidate therefore produces 4 validation scores. Average those 4 scores to obtain one mean inner-CV score for that learning rate.

Learning rate #14 validation scores1 mean CV score

Learning rate #104 validation scores1 mean CV score

Before averaging, this outer split has 40 raw inner-fold validation scores. After averaging, it has 10 mean CV scores. The learning rate with the best mean score is selected for this outer split.

4. The Outer Evaluation Step

Suppose the inner CV for the E-aside split selects learning rate 0.01. Now train one fresh model on all of A + B + C + D using 0.01, then predict the untouched E fold.

A+B+C+D→train with selected learning rate→E→outer score

Repeat the same process with D, C, B, and A kept aside in turn. This produces 5 outer evaluation scores.

Outer CV’s job: evaluate the result of the tuning procedure on data that did not participate in that split’s hyperparameter selection.

5. How the Five Outer Scores Are Used

Average the five outer scores:

nested CV score=s1+s2+s3+s4+s55

This average estimates how well the whole procedure — tune hyperparameters with inner CV, then train — generalizes.

6. Total Fits in the Worked Example

The fixed illustrative setup contains:

Inner tuning fits

5 outer splits × 10 learning rates × 4 inner folds = 200.

Outer refits

One fresh refit for each of the 5 outer splits = 5.

200+5=205model trainings

The number 205 belongs to this worked example, not to the source text as a universal nested-CV requirement.

7. The Terminology That Caused Confusion

Local hyperparameter selection

Inside each outer split, inner CV selects one learning rate for that split. Across five outer splits, these selected learning rates may differ.

Nested CV as a whole

Its purpose here is to evaluate the tuning procedure. The five local winners are not automatically combined into one final production learning rate.

Source boundary: the checklist states “inner CV tunes, outer CV evaluates.” The later question of choosing one final production hyperparameter is not explained in this page of the source; any full-data-CV workflow for that final choice is additional standard practice, not a statement from the checklist itself.

Final Mental Model

Inner CV: for one outer split, compare candidate hyperparameters and select the best mean inner-validation score.
Outer CV: train with that selected setting on the whole outer-training portion and judge it on the untouched outer fold.
Nested-CV result: average the five outer scores to estimate the generalization of the whole tuning procedure.

1. NMS: Keep the Strongest Box, Suppress Redundant Overlap

The book lists NMS = Non-Maximum Suppression as detection post-processing for removing overlapping redundant prediction boxes.

Suppose one dog produces three predictions:

BoxConfidenceRelation
A0.95Best box around the dog
B0.90Strongly overlaps A
C0.60Elsewhere

If A and B overlap above the chosen IoU threshold, NMS keeps the higher-confidence A and suppresses B. C can remain if it does not strongly overlap A.

If IoU(A,B)>threshold and score(A)>score(B), keep A and suppress B.
Practice checkpoint: with threshold 0.5, scores A=0.92 and B=0.87, and IoU(A,B)=0.72, the correct action is to keep A and suppress B.

2. WBF: Fuse Overlapping Boxes Instead of Deleting One

The book lists WBF = Weighted Boxes Fusion as a standard method for combining detection boxes, especially across multiple models.

NMS

A + B → keep the strongest box and suppress the redundant one.

WBF

A + B → combine them into one fused box.

Study expansion: the "weighted" part means higher-confidence boxes contribute more to the fused coordinates. So if A has confidence 0.9 and B has 0.6, the fused box tends toward A rather than lying exactly halfway between them.

3. EfficientNet: Compound Scaling

The book's representative EfficientNet idea is compound scaling: scale three dimensions together rather than enlarging only one.

compound scaling=depth↑+width↑+input resolution↑

Therefore, increasing only image resolution is not compound scaling by itself.

4. Compound Scaling Is Not an Ablation

Study clarification: this distinction came from the practice discussion rather than a separate claim in the book.

When you jointly increase depth, width, and resolution, you are evaluating a new scaled model configuration. You are asking whether the jointly scaled model works better.

An ablation asks a different question: which individual component caused the change?

ExperimentQuestion answered
Depth + width + resolution togetherDoes this jointly scaled configuration work better?
Depth onlyWhat happens if only depth changes?
Width onlyWhat happens if only width changes?
Resolution onlyWhat happens if only resolution changes?

So compound scaling is a model-scaling strategy; ablation is an experiment-design strategy for isolating effects. A scaled EfficientNet variant is usually still part of the same architecture family, not automatically a completely new architecture.

5. What "Increase Resolution" Means

The book notes that larger input sizes can improve score but cost more GPU memory.

Study clarification: increasing resolution normally means using a larger model input from the same source images; it does not, by itself, mean collecting a new dataset.

For example, if the original files are 1024×1024, a training pipeline might change from 224×224 inputs to 384×384 inputs. The larger input preserves more of the detail already present in the originals.

If the original image itself is only 224×224, resizing it upward to 384×384 does not manufacture genuine new visual detail.

1. Max Pooling: Keep the Strongest Local Response

A 2×2 max-pooling window replaces a small region of a feature map with its largest activation.

[0.10.20.90.1]→0.9

The key tradeoff practiced here: pooling preserves that a strong feature existed, but discards some information about its exact location inside the pooled region.

Tiny-test result: the main information discarded is the exact within-region position, not the fact that the detector fired strongly.

2. Receptive Field: Deep Neurons See More of the Original Image

A shallow CNN (Convolutional Neural Network) unit may depend on only a small patch of the input. Stacking convolution and pooling layers means a deeper unit indirectly depends on a much larger region of the original image.

deeper layer⇒larger receptive field

This supports the hierarchy described in the book: shallow layers capture edges and color blocks; middle layers capture textures and local shapes; deeper layers can represent larger semantic structures such as eyes, wheels, or faces.

3. Why Start from a Pretrained Backbone

Pretrained CNN backbones already contain reusable low- and mid-level visual features learned from large image datasets. For a smaller competition dataset, fine-tuning those learned features is usually a much stronger starting point than training a large network from random initialization.

pretrained backbone→fine-tune on competition data
Tiny-test result: with only a few thousand labeled medical images, start from a pretrained backbone and fine-tune it.

4. Small Targets Need Spatial Resolution

If an object occupies only a tiny part of the original image, aggressive downsampling can shrink it until it nearly disappears from later feature maps.

For small lesions, cars in satellite imagery, or other tiny targets, the book's practical direction is to preserve more spatial detail through a larger input size or less aggressive early downsampling.

Risk

Small target + heavy downsampling → too few feature-map pixels remain to represent it.

Adjustment

Larger input resolution or reduced downsampling preserves more information about the target.

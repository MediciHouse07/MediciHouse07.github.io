1. Why Not Flatten the Image into a Fully Connected Network?

A 224×224 RGB image has about 150,000 input values. A fully connected network links every neuron to all of them, creating a huge parameter burden. More importantly, it does not naturally exploit the image structure that nearby pixels matter together and that the same object can appear in different positions.

Practice check: when a cat moves from the left side of the image to the right, a plain fully connected network tends to treat those positions as different input patterns instead of automatically reusing the same detector.

2. CNN = Convolutional Neural Network

The book introduces CNNs through two image-friendly ideas: small local pattern detectors that slide across the image, and reuse of the same detector at every position.

Locality

A small kernel looks at a local patch rather than connecting one neuron to the whole image.

Reuse

The same kernel is applied at many positions, so the same pattern can be recognized wherever it appears.

3. Convolution Kernel = Pattern Detector

A convolution kernel is a small weight matrix, for example 3×3. At each position it multiplies its weights by the pixels under it and sums the result into one response value.

A kernel can become sensitive to a pattern such as a vertical edge, horizontal edge, color transition, or texture.

Practice check: high responses from a vertical-edge kernel mean those image locations strongly match the vertical-edge pattern.

4. Feature Map

A feature map is the spatial grid of response values produced after one kernel scans the whole image. Each cell answers: “How strongly does the local patch at this position match this kernel's pattern?”

5×5 image→2×2 kernel scans→4×4 feature map

So for a vertical-edge detector, the feature map is effectively a map of where vertical edges appear strongly. One convolution layer normally has many kernels, so it produces many feature maps.

5. Parameter Sharing

The same kernel weights are reused at every spatial position. A 3×3 kernel does not learn one set of nine weights for the top-left and another set for the bottom-right.

Consequence: the same pattern can be detected throughout the image while the parameter count stays far smaller than if every position had its own detector.

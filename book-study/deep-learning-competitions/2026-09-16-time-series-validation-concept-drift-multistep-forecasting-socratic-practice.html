1. Validation Split Must Match the Data Structure

TimeSeriesSplit

For time-related problems, validation must stay in the future of training. Random splitting can leak future information into the past.

GroupKFold

When one entity has several rows, keep that entity entirely on one side of a fold so the model cannot partly recognize it from training.

StratifiedKFold

When class imbalance matters and there is no time/group constraint, preserve roughly the same target-class proportions in each fold.

OOF = out-of-fold. For threshold metrics such as F1, stitch the fold-validation predictions into OOF predictions and tune the decision threshold there rather than blindly using 0.5.

2. Future Leakage Can Hide in Preprocessing

For a model trained on January–May and validated on June, statistics used by preprocessing must be fitted only on January–May.

OperationLeakage riskSafe version
Missing-value meanGlobal mean includes future dataUse only training/past data
Target encodingFuture target values enter the encodingUse a rolling or fold-safe target mean
StandardizationFull-data mean/std includes future informationFit on training, transform validation

3. Time-Series Model Choice Depends on the Scenario

The book does not treat one model family as universally strongest.

ScenarioStarting choice
Short series, strong seasonality, limited dataARIMA (AutoRegressive Integrated Moving Average), ETS (Error, Trend, Seasonality), or Prophet
Many related series plus strong external variablesLightGBM or XGBoost (Extreme Gradient Boosting) with lag and rolling-window features
Long series with complex dependenciesTFT (Temporal Fusion Transformer), N-BEATS, or PatchTST

4. Concept Drift

Concept drift means the historical relationship itself changes over time—for example after a pandemic, promotion policy, or regulation change.

The book suggests giving recent samples more weight and adding features such as “days from today” so the model can distinguish fresh data from old data.

5. Recursive Multi-Step Forecasting

Recursive forecasting trains a one-step model and repeatedly feeds its own previous predictions back as lag features.

y^t+1→y^t+2→y^t+3

If Day 1 is predicted as 105 but its unknown true value will later be 112, the Day-2 recursive prediction must use 105, because 112 is unavailable at prediction time.

Main weakness: early prediction errors become inputs to later steps, so errors can accumulate as the forecast horizon grows.

6. Direct Multi-Output Forecasting

Direct multi-output forecasting learns a different mapping: one historical input window maps directly to an entire future vector.

[yt-59,…,yt]→[yt+1,…,yt+30]

It is not “too good to be true”: the model has been trained on many historical examples of past-window → future-vector pairs.

Advantage

Day-1 prediction error is not fed back as Day-2 input, so recursive error accumulation is avoided.

Cost

The model has to learn many outputs together, so it generally needs more data and greater model capacity.

7. Validation Must Reproduce Real Inference

If the deployed model forecasts seven days recursively, CV (cross-validation) must also forecast those seven days recursively. It must not secretly replace a Day-1 prediction with the true Day-1 validation value before predicting Day 2.

Rule: validation procedure ≈ test-time procedure.

8. Uncertainty-Aware Forecasting: Introduced

The next idea introduced on page 39 was quantile regression or model ensembles when uncertainty itself matters. Instead of only one point forecast, the model can produce values such as the 10th, 50th, and 90th percentiles to describe a prediction interval.

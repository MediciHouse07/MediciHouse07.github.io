1. Label Smoothing

Hard classification targets can be softened slightly so the model is not trained toward absolute confidence.

1→0.950→0.05

For a two-class target, [1, 0] may become [0.95, 0.05]. In common libraries this can be applied inside the loss function rather than by rewriting the stored dataset labels.

Purpose: reduce overconfidence and make the model less eager to fit noisy labels as if they were perfectly certain.

2. CV Fold Variance and Seed Checks

A mean CV score can hide instability. For example:

0.91,0.90,0.76,0.92,0.89

The unusually weak fold is a warning that the validation distribution or training process may be unstable. Small gains such as 0.001 should be rechecked with different random seeds before being trusted.

3. Ensemble Diversity Comes First

Ensembling works when models make different mistakes. Useful diversity can come from different architectures, feature/input views, folds, or random seeds.

High prediction correlation: if two models correlate above about 0.95, their mistakes are often too similar for the ensemble to add much.

4. Simple and Weighted Averaging

Simple averaging gives every model equal influence. Weighted averaging gives stronger or more complementary models more influence.

p=0.5pA+0.3pB+0.2pC

The key rule is that weights should be validated on OOF predictions rather than chosen by intuition alone.

5. How to Tune Ensemble Weights on OOF

For two models, write the ensemble as:

p=wpA+(1-w)pB

Then test candidate values such as w = 0, 0.1, 0.2, …, 1 against the true training labels using the competition metric. If w = 0.7 scores best on OOF, use 0.7A + 0.3B on test predictions.

Implementation pattern: OOF predictions → search candidate weights → compute metric → keep the best validated weights.

6. Averaging Mainly Reduces Variance

If models make partly independent errors, averaging can cancel some of those errors. The goal is not to guarantee the single closest prediction every time; it is to make predictions less unstable and less likely to be wildly wrong.

100+110+953≈101.7

7. High-Recall Ensemble: Cast a Wide Net First

For screening tasks where missing a true positive is especially costly, a permissive first-stage rule can treat a sample as positive when any model raises a strong enough concern. This increases recall but also increases false positives.

Current stopping point: permissive / high-recall first, then the next study step is how the final threshold is raised and tuned to filter weak positives.

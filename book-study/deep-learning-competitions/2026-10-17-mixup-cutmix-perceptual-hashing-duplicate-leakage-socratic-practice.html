1. MixUp: Blend Images and Labels

MixUp blends two images and uses the same mixture proportions for the target.

0.7×cat image+0.3×dog image→[cat 0.7, dog 0.3]

The competition intuition in the book is regularization: the model should not rely too heavily on one brittle visual cue.

2. CutMix: Replace a Region and Mix the Label

CutMix pastes a region from one image into another. The label mixture approximately follows the area proportions.

75% cat area + 25% dog area→[cat 0.75, dog 0.25]
Tiny-test result: a 75% / 25% CutMix image should use approximately the same 75% / 25% soft target.

3. Duplicate Images Can Leak Across Train and Validation

If the same underlying image appears in both training and validation, the validation score can become artificially optimistic. The book specifically recommends perceptual hashing to help detect duplicates or near-duplicates before splitting.

Ordinary file hash

Compares exact file bytes. Resize or recompress the same picture and the hash usually changes completely.

Perceptual hash

Represents visual structure, so slightly resized or compressed versions can still have similar hashes.

4. What “Perceptual” Means

Perceptual means related to perception: how something is seen, heard, or otherwise sensed. In “perceptual hash,” the emphasis is on how similar two images look rather than whether their bytes are identical.

5. Study Expansion: dHash Intuition

Source boundary: the book recommends perceptual hashing, but does not explain the algorithm. The following dHash example is an explanatory expansion.

A simple difference hash (dHash) can resize an image to a tiny grayscale representation, compare neighboring brightness values, and encode each comparison as a bit.

Brightness sequenceNeighbor comparisonsHash bits
10, 20, 18, 3010<20, 20>18, 18<30101
11, 19, 17, 2911<19, 19>17, 17<29101

The pixel values changed, but the local brightness relationships stayed the same, so the toy perceptual hash stayed the same.

6. Comparing Perceptual Hashes

Perceptual hashes are conceptually bit strings. They are often displayed in hexadecimal because it is shorter.

10110100  →  B4

Two hashes can be compared with Hamming distance: the number of bit positions that differ. A small distance suggests strong visual similarity and therefore a possible duplicate.

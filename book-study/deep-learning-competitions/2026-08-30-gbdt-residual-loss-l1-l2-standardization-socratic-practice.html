1. Feature Selection and Unseen Categories

Three practical checks were reinforced: drop features with persistently zero importance, investigate features with strong train/test distribution drift, and do not automatically discard ID-like columns because they may encode order or grouping.

Unseen category rule: if test contains a category never observed in training, map it to an explicit unknown category rather than forcing it into a known class.

2. GBDT Means Gradient Boosting Decision Tree

A Gradient Boosting Decision Tree (GBDT) builds an ensemble sequentially. Each new tree is trained to correct what the current ensemble still gets wrong.

Tree 1→correction Tree 2→correction Tree 3→⋯

“Boosting” means repeatedly adding weak models to strengthen the ensemble. “Gradient” refers to choosing each correction according to the loss-reducing direction.

3. Squared-Error Regression: Residual Correction

For squared-error regression, the residual view is especially clean. The same input features are used at each round, but the new tree learns the remaining correction rather than the original target directly.

r1=y−y^1
r2=y−(y^1+y^2)
y^ final=y^1+y^2+y^3+⋯
Terminology correction: the sum is the final prediction, not the label. The true label y stays fixed.

4. Loss Function and the Meaning of “Gradient”

The loss is chosen for the task and normally kept fixed throughout one boosting run. The next tree follows the negative gradient of that same loss. Under squared error, that direction is proportional to the ordinary residual.

L=(y−y^)2
Important: the next tree does not predict the squared error itself. Under squared-error loss, it predicts a correction proportional to y − ŷ.

5. Which Regression Losses Fit Which Goal?

LossAppropriate use
L2 / squared errorStandard continuous regression; a natural default when large errors should receive stronger penalties.
L1 / absolute errorContinuous regression when robustness to large outliers matters.
HuberA compromise: L2-like near small errors and L1-like for large errors.
QuantileWhen the target is a chosen percentile rather than the conditional mean.
Logistic / cross-entropyClassification, not ordinary unrestricted continuous regression.
PoissonMost natural for non-negative count-style targets, not arbitrary continuous values.

6. L1 versus L2 Gradients

L1 / absolute error

L=|y−y^|

Its derivative with respect to the prediction is essentially ±1 away from zero and is not differentiable exactly at zero; optimization can use a subgradient.

L2 / squared error

L=(y−y^)2

The gradient magnitude grows with the size of the error and naturally shrinks as the prediction approaches the target.

Optimization intuition: L1 can be less smooth near the optimum, while L2 gives size-sensitive gradients. Huber is often useful when both smooth local convergence and outlier robustness matter.

7. Standardization: Trees versus Neural Networks

Tree models mainly split by ordering and thresholds, so changing a feature's unit usually does not fundamentally change the split logic. Neural networks combine feature values numerically, so very different feature scales can make optimization harder.

x′=x−μσ
Practical rule: LightGBM-style tree models usually do not require standardization; a neural network such as an MLP (Multilayer Perceptron) usually benefits from it.

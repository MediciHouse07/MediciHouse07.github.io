1. Experiment Records: One Change at a Time

An experiment log is useful only if a result can be attributed to a clear change. If model, learning rate, and augmentation all change together, a better CV score does not tell us which change caused the gain.

Record: what changed, why it might help, CV/LB results, resources, key hyperparameters, seed, saved OOF/weights, and the conclusion.

2. Failed Experiments Still Matter

A failed experiment is still evidence. Recording it prevents repeating the same dead end later and makes the competition history reproducible.

Reproducibility bundle: code + configuration + random seed + data version.

3. Target Encoding

Target encoding replaces a categorical value with a statistic of the target for that category, usually its mean.

Example: in a static loan-default dataset, suppose the training portion contains:

Teacher

Targets: 0, 0, 1

Encoding: 1/3 ≈ 0.33

Engineer

Targets: 0, 1, 1, 1

Encoding: 3/4 = 0.75

category→mean target among allowed training rows

4. Why Target Encoding Is Not Automatically Leakage

Using labels from the training portion to build a category statistic is legitimate because those labels are available when fitting the model. Leakage happens when the row being evaluated contributes its own target, or when information unavailable at prediction time contributes to its encoding.

5-fold CV rule: when encoding the held-out fold, compute category statistics from the other four folds only.

For the final test set, the mapping can use all labeled training rows because those labels are genuinely known before test prediction.

5. Time Series Adds a Stricter Constraint

Target encoding is not restricted to time-series problems. In ordinary tabular CV, the main rule is to exclude the row/fold being predicted. In time series, the encoding must additionally respect chronology: future targets cannot be used to encode earlier rows.

6. Frequency Encoding

Frequency encoding replaces a category with how often it appears. It does not use target labels.

merchant X appears 500 times→frequency encoding = 500

If 50 of those 500 rows are fraud, the corresponding target encoding would be:

50500=0.10
Distinction: frequency encoding = occurrence count; target encoding = target statistic.

7. Numerical Transforms: Start of the Next Topic

For a strongly right-skewed numerical feature, a log transform can compress extreme values:

x→log(1+x)

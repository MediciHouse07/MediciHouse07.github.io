Laplace Transform – Wrap-Up (Socratic Study)

Topic Differential Equations → Algebra via Transform Book Boyce & DiPrima – Elementary Differential Equations

1. Why Laplace Exists

We started from a core difficulty: differential equations mix a function y(t) with its derivatives, making direct algebraic solving impossible.

Goal: convert differential equations into algebraic equations.

2. The Key Idea (Lens Interpretation)

The Laplace transform acts like a lens:

Small s → long-term behavior (slow decay lens)
Large s → short-term behavior (early-time focus)

This is achieved by weighting the function with an exponential decay e^{-st}.

3. Definition

L{y(t)} = Y(s) = ∫₀^∞ e^{-st} y(t) dt

This creates a new representation Y(s), not a single number but a full function of s.

4. Why Exponentials?

Exponentials are stable under differentiation:

d/dt (e^{-st}) = -s e^{-st}

This is why integration by parts works cleanly.

5. Core Result (Derivative Rule)

L{y'} = sY(s) − y(0)
L{y''} = s²Y(s) − s y(0) − y'(0)

Derivatives become algebraic expressions + initial conditions appear naturally.

6. Example Result

For y' + 2y = 0, y(0)=3:

(s+2)Y = 3 → Y = 3/(s+2)

Inverse gives y(t) = 3e^{-2t}

7. Inverse Idea

The inverse Laplace transform retrieves y(t) from Y(s) using a transform table (dictionary between domains).

8. Big Picture

Differential equation → Laplace transform → algebraic equation → inverse transform → solution

Key Insight: The transform doesn’t solve equations directly—it changes the representation where solving becomes simple.

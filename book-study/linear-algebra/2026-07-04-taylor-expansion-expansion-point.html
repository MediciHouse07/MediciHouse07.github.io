1. The General Taylor Formula Has Two Points

Known point

The point where the function value and derivatives are known is the expansion point.

a=expansion point

Target point

The point where the function is being predicted can be named separately.

z=point to predict
f(z)≈f(a)+f′(a)(z-a)+f″(a)(z-a)22!+⋯

Key idea: a is not special by itself. It is just the name for the point where the approximation is centered.

2. Why Gradient Descent Uses x Instead Of a

In gradient descent, the current position is normally named x. So the Taylor expansion is centered at the current point.

a=x

Expand around the current point.

z=x+εu

Predict after a small step in direction u.

Substituting those names into the general formula gives:

f(x+εu)≈f(x)+f′(x)εu+⋯

3. Correction From the Photo

The mistaken move

The attempted rewrite effectively expanded around the wrong center.

wrong center:-εu

The right move

For gradient descent, expand around the current position because that is where the local information is known.

right center:x
Rule: Taylor expansion is always centered at the point where the local information is known.

4. Core Philosophy

Stand at current point
Measure local information
Predict nearby values
Choose a useful step
local information at current point→prediction near current point

Gradient descent uses the first-order version of this idea. Newton's method uses the second-order version.

5. Memory Hook

Taylor expansion predicts a function near the current point using information measured at that current point.

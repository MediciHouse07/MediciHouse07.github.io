1. How To Choose the Function

Common mistake

For approximating sqrt(4.01), choosing f(x)=x^2 feels nearby, but it is not the function being evaluated.

wrong setup: f(x) = x^2

Correct setup

The function should come directly from the expression we want to approximate.

sqrt(4.01) means choose f(x) = sqrt(x)
Memory rule: Taylor expansion approximates the function you are trying to evaluate.

2. Why Expand Around 4 for sqrt(4.01)?

We choose the expansion point a=4 because it is close to 4.01 and easy to compute.

f(x)=sqrt(x), a=4, x=4.01
StepValueMeaning
Function valuef(4)=2Known exact value
Derivativef'(x)=1/(2 sqrt(x))Slope of sqrt(x)
Derivative at 4f'(4)=1/4Local slope
First-order estimate2 + (1/4)(0.01) = 2.0025Approximation of sqrt(4.01)

The correction term is positive because both f'(4) and 4.01-4 are positive. Since sqrt(x) is increasing, moving right from 4 should increase the value slightly above 2.

3. Accuracy: Why the Tangent Line Works Here

First-order Taylor is accurate here because 4.01 is extremely close to 4. The tangent line is a local model, and local models work best near the expansion point.

4. e^0.1 Quiz: Setup Before Calculation

For e^0.1, the correct setup is:

f(x)=e^x, a=0, target x=0.1

The point a=0 is good because e^0=1, every derivative of e^x is still e^x, and 0 is close to 0.1.

Before calculation, we predicted the first-order approximation would be slightly smaller than the true value because e^x curves upward.

5. Curvature Tells Underestimate vs Overestimate

Second derivativeShapeFirst-order tangent line
f''(a) > 0Concave upUnderestimates nearby values
f''(a) < 0Concave downOverestimates nearby values

This was the strongest sign that the idea is becoming geometric, not just symbolic.

6. Bridge Back To Gradient Descent

The next question connects Taylor expansion directly to optimization:

f(x+h) approx f(x) + f'(x)h

To make the approximation smaller, the product f'(x)h must be negative. That means h should have the opposite sign from f'(x).

choose h opposite f'(x) -> move downhill

This is the conceptual birth of gradient descent.
